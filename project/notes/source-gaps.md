## How to Write About Gaps

Use clear language:

> The current documents do not provide enough detail about this topic. To support this slide, we should search for an official technical source, such as a project annex, a DNIT manual, a DER/SP manual, or a geological map.

## Rules
- Do not guess missing technical values.
- Do not present administrative contract text as engineering design detail.
- Prefer official and technical sources.
- Add any extra source used to `presentation/references.md`.
- Ask the professor or monitor if external sources are allowed.
