# Source Fit Comparison

## Purpose
This file compares the three project sources and shows what each one contributes to the presentation.

## Source Roles

| Source | Best use | Limits |
|---|---|---|
| `Aula15_GEO-31_2020.pdf` | Main technical theory about roads and Engineering Geology. | Needs a real example to make the presentation concrete. |
| `CONTRATO-RODOANEL-NORTE-N-0521-ARTESP-2023_ASSINADO.pdf` | Real case-study context for a major road project. | May be more administrative than technical. |
| `Orientações para os Trabalhos em Grupo_GEO-31.pdf` | Rules and expectations for the group presentation. | Does not provide the road theory itself. |

## Current Judgment
The safest structure is:

1. **Theory:** Aula 15.
2. **Case study:** Rodoanel Norte contract.
3. **Format and rules:** Orientation PDF.

Do not rely only on the contract for technical explanation unless specific technical sections are found.
